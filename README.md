# Python_CLI_chat
Terminal-based chat with GPT-4.1 Mini utilitizing the OpenAI Responses API

Terminal-based chat where you add your OpenAI API key to the .env and are able to send and receive messages from GPT-4.1 Mini.

Also includes tool-calling functionality where the program will be terminated if the user wishes to end the conversation, simply needing to tell the model that you want to do so.
